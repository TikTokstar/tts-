# Български TTS бот за TikTok Live

Чете съобщенията от чата ти на глас, на български, докато streamваш.
Разбира и **шльокавица** — български, писан на латиница или с цифри
(`6te doida` → „ще дойда“, `ku4e` → „куче“, `mnogo qko` → „много яко“).

Работи изцяло на процесор. Не иска видеокарта, torch или локални
невронни модели.

## Какво прави

| | |
|---|---|
| **Чете чата на глас** | Всяко съобщение от TikTok Live чата ти |
| **Разбира шльокавица** | `zdr kvo stava` → „здр кво става“ |
| **Не сбърква английския** | `gg wp` → „джиджи дабълю пи“, а не „гг вп“ |
| **12 гласа** | Всеки зрител звучи различно, но винаги еднакво |
| **Модерация** | Черен списък, изчаквания, лимити, дължина |
| **Контролен панел** | `http://localhost:8777`, всичко се сменя в движение |
| **Voicemeeter** | Изходното устройство се избира по име |

## Инсталация

**Нужен е само Python 3.11.** Всичко останало се инсталира само.

1. Ако нямаш Python: изтегли го от
   [python.org/downloads](https://www.python.org/downloads/)
   При инсталацията **задължително** сложи отметка на
   **„Add Python to PATH“**.

2. Щракни два пъти върху **`run.bat`**.

Толкова. Първото пускане отнема около минута — създава се виртуална среда
и се теглят пакетите. Следващите пускания са мигновени.

> `run.bat` прави всичко сам: среда, пакети, проверка, пускане.
> Не е нужно да отваряш команден ред.

<details>
<summary>Ако предпочиташ ръчно</summary>

```bat
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```
</details>

## Първо пускане

1. Пусни `run.bat`. Панелът се отваря сам на
   **http://localhost:8777**
2. В горното поле напиши своя TikTok потребител. Приема се във всякакъв вид:
   - `@moeto_ime`
   - `moeto_ime`
   - `https://www.tiktok.com/@moeto_ime`
3. Натисни **Свържи**.

Името се запомня и следващия път е попълнено. Ако искаш ботът да се
свързва сам при пускане, сложи отметка на **„Свързвай се автоматично“**.

### Индикаторът за състояние

| Надпис | Какво значи |
|---|---|
| **Свързване** | Опитва се в момента |
| **На живо** | Свързан е, чете чата |
| **Не е на живо** | Още не си пуснал stream — проверява пак на всеки 30 с |
| **Пресвързване** | Връзката падна, опитва пак с нарастващо изчакване |
| **Прекъснато** | Ти си прекъснал |
| **Грешка** | Виж съобщението под индикатора |

**Може да пуснеш бота преди streama.** Ще чака и ще се закачи сам щом
започнеш.

## Voicemeeter

За да чуват гласа и зрителите ти, изпрати го към Voicemeeter, а не към
колоните.

1. В панела, раздел **Звук** → **Изходно устройство**
2. Избери **`Voicemeeter Input`** (или `Voicemeeter Aux Input`)
3. В OBS/TikTok Studio вземи изхода на Voicemeeter

Устройството се пази **по име**, не по номер — затова закачането на
слушалки не разбърква настройката.

Ако искаш да чуваш и ти, пусни Voicemeeter да минава към твоите
слушалки (A1).

## Гласове

Български има само два неврални гласа (Борислав и Калина), затова
разнообразието идва от **пресети**: базов глас + скорост + височина + сила.

Готови са 12: Борислав, Калина, Дядото, Хамстер, Спикер, Пиян, Детето,
Бабата, Гигантът, Бързакът, Шепот, Роботът.

### Кой зрител какъв глас получава

По подразбиране — **лепкав глас**: от името на зрителя се смята хеш и
той винаги получава същия глас. Един и същ човек звучи еднакво всеки път.

### Зрителите избират сами

В чата:

```
!glas       — колко гласа има
!glas 3     — избира глас номер 3
!glas Хамстер
```

Изборът се помни в `voices_state.json`. Потвърждението се чете **с новия
глас**, за да го чуе веднага.

### Ти командваш

В панела, раздел **Гласове**:
- **Пресет за проба** + бутон **Пробвай** — чуваш го веднага
- **Наложи един глас на всички** — игнорира избора на зрителите
- **Изчисти запомнените гласове** — всички се връщат на лепкавия хеш

### Свои пресети

Отвори `voices.json` и добави:

```json
{
  "id": "moiat_glas",
  "name": "Моят глас",
  "voice": "bg-BG-BorislavNeural",
  "rate": "-30%",
  "pitch": "+20Hz",
  "volume": "+0%",
  "description": "Бавен и висок"
}
```

`rate` и `volume` са в проценти със знак, `pitch` е в херци със знак.
Имената на гласовете се сверяват при всяко пускане — ако сгрешиш, ботът
казва кой пресет е счупен и минава на работещ вместо да спре.

## Модерация

Всичко се сменя от панела и важи **веднага**, без рестарт.

| Настройка | По подразбиране | Какво прави |
|---|---|---|
| Максимална дължина | 200 | По-дългите се отрязват с „...“ |
| Изчакване на зрител | 8 с | Един човек не може да спами |
| Съобщения за минута | 20 | Общ таван при вълна |
| Повторения | 30 с | Едно и също от същия човек се пропуска |
| Дължина на опашката | 15 | При препълване пада **най-старото** |
| Само с емоджи | вкл. | „😂😂😂“ няма какво да се чете |
| Само с линк | вкл. | Гол линк не се чете |

**Изключени по подразбиране** (защото смисълът е да се чете всичко):

- **Само последователи** — само тези, които те следват
- **Само дарители** — само подарилите
- **Само съобщения с префикс** — чете само започващите с `!tts`

> Модераторите минават през филтрите „само последователи/дарители“.

Отхвърлените съобщения **не изяждат** общия лимит — вълна от емоджита не
пречи на истинските съобщения.

## Черен списък

Файлът `blocklist.txt`. **Презарежда се сам** — редактирай го докато
streamваш, промяната важи от следващото съобщение.

```
# Ред с диез е коментар

идиот                 # цяла дума, без значение от регистъра
re:(?i)\bsub4sub\b    # регулярен израз
/^реклама/            # същото, с наклонени черти
```

Думите съвпадат само като **цели думи** — „пич“ няма да спре „спичам“.

Счупен регулярен израз се докладва в панела и **не поваля** останалите
правила.

Работят и докато си в игра на цял екран:

| Клавиши | Действие |
|---|---|
| `Ctrl + Alt + S` | Пропусни текущото съобщение |

Сменят се в `config.json`, раздел `hotkeys`. Ако не тръгнат (Windows
понякога не дава достъп до клавиатурата), бутоните в панела работят
винаги.

## Транслитерацията отблизо

Това не е проста таблица буква-за-буква, защото такава не може да работи.
Много букви са двусмислени и правилният избор зависи от **думата**:

| Шльокавица | Правилно | Защо е трудно |
|---|---|---|
| `tsvete` | цвете | `ts` = **ц** |
| `otstrani` | отстрани | ...но тук `ts` = **т**+**с** |
| `moyat` | моят | `y` = **й** |
| `kyde si` | къде си | ...но тук `y` = **ъ** |
| `utre` | утре | `u` = **у** |
| `lubov` | любов | ...но тук `u` = **ю** |
| `az sum tuk` | аз съм тук | ...а тук `u` = **ъ** |
| `naiven` | наивен | `ai` = **а**+**и** |
| `mai 6te vali` | май ще вали | ...но тук `ai` = **ай** |

Затова ботът **генерира кандидати** и ги оценява спрямо честотен речник
на българския (50 000 думи от субтитри) плюс символен модел. Печели
кандидатът, който изглежда най-много като истински български.

Езикът се решава на ниво **изречение**, не на дума. `be` е честа
английска дума, но в „kak si be“ съседите я издават като българското „бе“.

Английските думи не се сричкуват — минават през фонетичен речник, за да
звучат смислено:

```
ok      → оукей          gg      → джиджи
lol     → лол            gaming  → гейминг
```

Пробвай сам от команден ред:

```bat
.venv\Scripts\python translit.py "6te doida sled malko"
.venv\Scripts\python translit.py --explain "kak si be"
.venv\Scripts\python translit.py --repl
```

`--explain` показва оценките за всяка дума — удобно, ако нещо се чете
странно.

Ако някоя дума упорито не се получава, добави я в `data/bg_slang.txt`
(дума и тежест на ред), а английските произношения са в
`data/en_phonetic.json`.

## Настройки

Всичко живее в `config.json` и се променя от панела. Ръчно се редактира
само ако искаш нещо извън панела.

| Файл | Какво е |
|---|---|
| `config.json` | Всички настройки |
| `voices.json` | Гласовите пресети |
| `blocklist.txt` | Забранени думи и изрази |
| `voices_state.json` | Кой зрител какъв глас си е избрал |
| `.env` | Само `TIKTOK_SESSIONID`, ако потрябва |
| `audio_cache/` | Кеширан звук — трие се спокойно |
| `cache/` | Ускорява пускането — трие се спокойно |

### TIKTOK_SESSIONID

**По подразбиране не ти трябва.** Ботът работи без никакви данни за вход.

Трябва само ако:
- TikTok блокира анонимната връзка
- streamът е с възрастово ограничение

Тогава копирай `.env.example` като `.env` и попълни. Как се взима — пише
вътре във файла.

> `sessionid` е равносилен на парола. Никога не го показвай на stream и
> не го качвай в git (`.env` вече е в `.gitignore`).

## Ако нещо не работи

### Не се свързва

| Съобщение | Какво да направиш |
|---|---|
| „Няма такъв потребител“ | Сгрешено име. Пробвай с адреса на профила. |
| „не е на живо“ | Нормално. Чака те. Пусни streama. |
| „TikTok ограничава заявките“ | Изчакай малко. Само ще се пробва пак. |
| „блокира анонимната връзка“ | Попълни `TIKTOK_SESSIONID` в `.env`. |
| „Сървърът за подписване не отговаря“ | Временно е. Само се оправя. |

### Няма звук

1. **Провери устройството**: панел → Звук → Изходно устройство
2. **Провери дали не е заглушено**: бутонът горе вдясно
3. **Пробвай глас**: панел → Гласове → Пробвай
4. От команден ред:

```bat
.venv\Scripts\python audio.py --list-devices
.venv\Scripts\python tts.py --say "Проба едно две три"
```

Ако `--list-devices` не показва нищо, преинсталирай:

```bat
.venv\Scripts\pip install --force-reinstall sounddevice
```

### Гласът се бави

- **Провери интернета** — синтезът минава през сървъри на Microsoft
- Първото изричане на нова фраза е по-бавно; повторените идват от кеша
- Ако закъснява постоянно, намали „Съобщения за минута“

### Съобщенията се четат странно

Отвори панела и виж таблицата долу: показва **оригинал → изговорено**
за всяко съобщение. Така се вижда веднага дали проблемът е в
транслитерацията или в самото съобщение.

После:

```bat
.venv\Scripts\python translit.py --explain "проблемният текст"
```

### Панелът не се отваря

Провери дали порт 8777 не е зает. Смени го в `config.json` →
`panel.port`.

### Нещо съвсем е счупено

Изтрий папките `.venv`, `cache` и `audio_cache` и пусни `run.bat` пак.
Настройките ти (`config.json`, `voices.json`, `blocklist.txt`) остават.

## Как е устроено

```
Чат съобщение
     ↓
 модерация          филтри, лимити, черен списък
     ↓
 транслитерация     шльокавица → кирилица
     ↓
 избор на глас      лепкав хеш или избор на зрителя
     ↓
 опашка             най-много 15, пада най-старото
     ↓
 синтез             edge-tts + кеш на диска
     ↓
 изсвирване         една опашка, без застъпване
```

| Файл | Отговаря за |
|---|---|
| `main.py` | Сглобява всичко, конвейерът |
| `translit.py` | Шльокавица → кирилица |
| `tts.py` | Гласове и синтез |
| `audio.py` | Устройства, декодиране, изсвирване |
| `moderation.py` | Филтрите |
| `tiktok_source.py` | Връзката с TikTok |
| `config.py` | Настройки |
| `panel/` | Контролният панел |

Връзката е зад интерфейса `EventSource`, така че по-късно може да се
сложи TikFinity WebSocket, без да се пипа останалото.
